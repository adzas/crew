# Rola kapitana

## Wymagania: 

### Requirement: kapitan jest wymaganym członkiem załogi

#### Scenario: Gra jest uruchamiana [1]

- **WHEN** host chce uruchomić grę, ale rola kapitana nie jest obsadzona
- **THEN** gra nie uruchamia się.

#### Scenario: Gra jest uruchamiana [2]

- **WHEN** host klika w przycisk uruchamiający grę, jeden z graczy będzie sterował rolą kapitana
- **THEN** gra uruchamia się.
